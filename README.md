Hey there! I’ve built this Expense Tracker App to help you keep track of your expenses in an easy and organized way. It’s a full-stack app that uses React for the frontend, Node.js and Express for the backend, and MongoDB for the database.

What it does:
Frontend:

The app is built with React, making it super interactive and user-friendly.

I used TailwindCSS for the design, so it’s clean and responsive.

You can easily add your expenses, see them listed, and even filter them by category.

There’s a handy feature that warns you if you exceed a monthly expense limit.

Backend:

The backend is built with Node.js and Express, which handle all the API requests.

MongoDB is used for storing the expenses, so you don’t have to worry about losing any data.

I’ve set up endpoints to add, get, and remove expenses.

Database:

Expenses are saved in MongoDB, so you can come back anytime to review your spending history.

Expense Limit Feature:

I’ve added a cool feature that alerts you when your total expenses for the month go over a predefined limit.

Tech Stack:
Frontend: React, TailwindCSS, Axios

Backend: Node.js, Express

Database: MongoDB

API: RESTful API to handle expenses

Environment: Local development with MongoDB

How to Get It Running:
Clone the repo.

Install the backend dependencies:

Run npm install in the backend folder.

Start the backend server with:

node server.js.

Install the frontend dependencies:

Run npm install in the frontend folder.

Start the frontend app:

Run npm start.

And there you go, you’ll have a fully functional expense tracker up and running!
